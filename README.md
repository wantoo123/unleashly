# Unleashly

本地优先的 AI 视觉创作工作台。

Unleashly 将无限画布、图片与视频生成、素材库、提示词库、任务中心和插件系统整合到一个桌面客户端中。项目、素材与生成记录默认保存在本机，API Key 由系统密钥库保护。

## 功能

- **无限画布**：用节点组织提示词、参考图、生成结果与配置，支持连线、分组、缩放、小地图、撤销重做和媒体拖入。
- **生图工作台**：文生图、参考图改图、批量生成、结果预览，以及分辨率、比例、质量、张数等参数控制。
- **视频创作台**：文生视频、首尾帧与参考生成，支持生成历史和结果管理。
- **素材库**：收藏与管理图片、视频和文本素材，支持标签、搜索、导入导出和批量操作。
- **提示词库**：浏览、筛选、复制和收藏提示词，也可以把提示词保存为素材。
- **任务中心**：查看排队、运行和历史任务，支持进度、耗时、成功率、用量统计、取消、重试和清理。
- **多模型渠道**：支持 OpenAI 兼容接口与 Gemini，渠道、模型与默认能力可以分别配置。
- **后台生成**：长任务在主进程继续运行；窗口关闭时可保留在托盘，完成后发送系统通知。
- **本地优先**：项目与媒体保存到本机应用数据目录，支持项目、素材和配置的导入导出。
- **诊断与日志**：内置日志、崩溃报告和诊断包导出，方便排查运行问题。

## 使用

### 配置模型渠道

1. 打开 **配置 → 渠道**。
2. 添加渠道，填写 Base URL、API Key，并选择或添加模型。
3. 在 **偏好设置** 中为图片、视频、文本和音频分别选择默认模型。

浏览器中的旧数据不会自动出现在桌面客户端中，可通过项目 ZIP、素材 ZIP 或配置 JSON 导入。

### 开始创作

- **我的画布**：新建画布后，把提示词、参考图和生成结果作为节点连接起来。
- **生图工作台**：输入提示词、添加参考图并调整生成参数。
- **视频创作台**：输入提示词或参考图片，选择时长、清晰度和模式。
- **提示词库 / 我的资产**：查找灵感，保存常用提示词和生成结果。

### 任务与后台运行

生成任务会进入 **任务中心**。可以查看执行状态、取消运行中的任务、重试失败任务，或清理已完成记录。

有任务运行时关闭窗口，应用会保留在系统托盘继续生成；完成后会发送系统通知。

## 数据与隐私

数据默认保存在本机：

- Windows：`%APPDATA%\unleashly`
- macOS：`~/Library/Application Support/unleashly`
- Linux：`~/.config/unleashly`

其中包含项目、素材、生成记录、任务数据、日志和诊断信息。API Key 与 WebDAV 密码由操作系统密钥库加密保存，不会写入导出的配置文件。

- 默认不需要登录，也不会上传项目或生成内容。
- WebDAV 同步为可选功能，由用户自行配置。
- 「配置 → 诊断与日志」可导出诊断包；诊断包包含日志、崩溃报告和脱敏后的渠道配置，不包含生成内容或密钥。
- 清理应用数据前，建议先导出需要保留的项目、素材和配置。

## 系统要求

- Windows、macOS 或 Linux 桌面环境。
- 从源码构建需要 Node.js 22+ 与 pnpm 12+。

## 从源码运行

```bash
pnpm install
pnpm dev
```

如果 Electron 二进制没有自动下载：

```bash
node node_modules/electron/install.js
```

常用命令：

```bash
pnpm build       # 构建应用
pnpm preview     # 使用生产构建启动 Electron
pnpm package     # 生成未打包目录
pnpm dist        # 生成安装包
```

## 兼容性说明

- 画布 Agent 能力需要单独运行 `@basketikun/canvas-agent`；客户端保留 Agent 面板与连接配置。
- 运行时插件属于高信任代码，建议只安装可信来源的插件。
- 浏览器版与桌面版的数据目录彼此独立；跨端迁移请使用项目、素材和配置的导出/导入功能。

## Phase 2：Provider Gateway 与任务系统（当前）

目标：把生成调用从渲染层迁到主进程，形成可恢复、可观测的任务系统。

- [x] 定义图片/视频/文本/音频/3D 的 Provider 接口
- [x] 把 `services/api/image.ts`、`video.ts` 的协议适配迁到主进程
- [x] 统一请求超时、重试、退避和错误分类
- [x] SQLite 或 JSON 持久化 Job Queue（实现为原子写入的 JSON 队列）
- [x] 任务并发、优先级、取消、重试、恢复
- [x] 应用重启后恢复视频/长任务轮询
- [x] 系统通知与托盘后台生成
- [x] 耗时、成功率、Token/图片用量统计
- [x] 任务中心页面
- [x] 本地代理降级为调试/兼容入口
